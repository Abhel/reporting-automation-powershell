# Reporting Automation PowerShell

PowerShell automation tool with GUI support for generating reports individually or in batches.

## Overview
This project automates report generation using a PowerShell-based GUI. It supports both single and batch processing, improving efficiency and reducing manual workload.

## Features
- GUI interface for easy operation  
- Single and batch report generation  
- Automated file handling and output  
- Error handling and progress tracking  

## Future Enhancements
- Add logging and export options  
- Integrate with cloud storage for backups
